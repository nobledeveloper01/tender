# The recording kit — what a speaker is handed

Tender says the denomination in the user's own language from a bundled
recording. Everything else stays in English, through VoiceOver, because
VoiceOver has no voice for any Nigerian language and a blind Nigerian iPhone
user already lives in that.

That makes the list short: **twelve lines per language** — eight values and
four connecting words — in Naijá, Hausa, Yorùbá, Igbo and Fulfulde. Sixty
recordings in all. Today all sixty are placeholders that say, in English,
that they are placeholders and which language belongs there, and the app
refuses to offer a language with a placeholder in it. The day Hausa's twelve
come back, Hausa appears in the list.

## Getting the script

```
make recording-kit L=ha
```

prints the twelve lines for Hausa, numbered, with the English beside each.
The lines are read out of the code — the same enum the app composes
sentences from — so the script cannot fall behind the app.

## Recording

- A quiet room. The phone's own voice memo app is fine.
- One take per line. Say it plainly, once, as you would to a person holding
  the note. Not read; said.
- Name each file by its line number (`01`, `02`, …) or by its stem
  (`n500`, `new-design`, …). Any format: m4a, wav, aiff, mp3.
- The four connecting words matter as much as the values: *I think … Check.*
  is how the app hedges, and a hedge should sound like one in every language.

## Bringing them back

```
make recording-import L=ha D=~/Desktop/hausa
```

converts every take to the bundled format (AAC-LC, 16 kHz, mono, 32 kbps),
files it, and strikes it off `placeholders.txt`. A take that would replace a
real recording is refused unless `FORCE=1`. Then:

```
make audio-check
```

counts what is left. Green when every clip is a recording.

Generated by `make recording-kit L=<code>`; the Hausa one is shown as the
example.

per line, named by its number or its stem. Quiet room, phone at arm's length.
